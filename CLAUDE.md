# Cartons

Package tracker for iPhone and Mac (one target, `supportedDestinations: [iOS, macOS]`). Paste a UPS number or link, get a countdown to the delivery day. No account, no server.

## How tracking works
UPS's API needs a UPS shipping account for keys, and ups.com blocks plain HTTP (Akamai). So the app loads UPS's own tracking page in a hidden `WKWebView` and reads the visible text (`app/Cartons/UPSPage.swift`). `UPSPage.parse` is the fragile part: it keys off labels like "Estimated delivery", "Last Location", "Ship To" and the progress step marked "active". When UPS rewords its page, fix `parse` and add the new page text to `tests/ParseCheck.swift`. Run `tests/run.sh` after any change. The official API (`cli/ups.py`) is the upgrade path once keys exist.

## Layout
- `app/Cartons/`: SwiftUI. `Brand` registers Cartons Sans and `Font.carton(_:)` sets it at Dynamic Type sizes. `Store` (list, archive, iCloud key-value sync), `PackageList` (Packages and Archive tabs), `SettingsView` (profile, sync), `UPSPage` (the reader), `Mascot` (Tuck, the splash and onboarding).
- `Cartons.icon`: Icon Composer bundle, the source of the app icon. Drawing in `brand/src/box.svg`. `Tuck.icon` is the alternate icon (iOS only, picked in Settings), layers drawn in `brand/src/tuck/`.
- `brand/`: `BRAND.md` is the rulebook, `tokens.css` the web tokens, `cover/` the App Store cover.
- `fonts/`: Cartons Sans (Inter, OFL, renamed). Rebuild with `uv run --with fonttools --with brotli scripts/gen_font.py`, then `--check`.
- `docs/`: App Store listing, whitepaper, security.
- `cli/ups.py`: official-API tracker, needs `UPS_CLIENT_ID` and `UPS_CLIENT_SECRET`.

## Mac
Same sources. UIKit-only calls sit behind `#if os(iOS)` or the helpers at the bottom of `Brand.swift` (`cartonList`, `inlineTitle`, `Clipboard`). Entitlements are split by SDK: `app/Cartons.entitlements` (iOS, generated by xcodegen) and `app/Cartons-macOS.entitlements` (sandbox, network client, iCloud key-value). A launch through `open -n` can restore with no window; `open` the app again (a reopen event) to get one before `screencapture -l`. Build unsigned with `xcodebuild -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO CODE_SIGN_IDENTITY=""`.

## QA
Use the dedicated `Cartons-QA-iPad` simulator (A2D1628A), not the shared booted one; other sessions drive that. Launch flags: `-add <number or link>` adds a package, `-tab 0|1|2` opens a tab, `-open` opens the first package, `-addsheet` opens Add, `-onboarding` (with `-page 0...3`) shows the first-run pages, `-splash` holds the splash. `-demo` skips onboarding.

## Web
`wrangler.toml` deploys one Worker named `carton` to cartons.jaybulb.com: `web/` is the landing page with the working web app under the hero (`web/app.js`, list in localStorage), and `/api/track/<number>` reads UPS's page with Cloudflare Browser Rendering (`worker/index.js`). ups.com aborts a cold headless visit; loading the UPS home page first with a desktop Safari user agent picks up the cookies that let the tracking page through. `worker/parse.js` is the JS twin of `UPSPage.parse`: change both together and run `node worker/parse.test.mjs`. Results cache for 15 minutes. The free plan allows only a few new browsers a minute (429 "Rate limit exceeded"), so `getBrowser` reconnects to an idle warm session (kept alive 10 minutes) and retries a refused launch; with the 15 minute cache that handles back-to-back lookups. A `LIMITER` binding caps each visitor at 10 lookups a minute, but Cloudflare's limiter is loose by design, so treat it as a brake, not a wall. UPS's icon names leak into page text as words (`check_circle`); both parsers strip snake_case tokens first. Deploy is `npx wrangler deploy`; a push deploys nothing. Never put a real tracking number on the public page; `#1Z...` in the URL adds one locally and the hash never reaches the server.

## App Store

Kept on purpose: bundle id `com.nulljosh.carton` (bound to the record), SKU carton, the Worker name `carton`, and the web storage key `carton.parcels` (renaming it would wipe browser lists). carton.jaybulb.com redirects to cartons.jaybulb.com.
